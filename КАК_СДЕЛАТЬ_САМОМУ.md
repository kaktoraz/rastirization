# Как сделать всё это самому (инструкция)

Короткий ответ: **да, можно и нужно всё трогать самому.** Проект — полностью ваш:
программа, отчёт, презентация и все результаты лежат у вас, исходный код открыт,
и вы можете менять в нём что угодно — вплоть до собственного метода.

Ниже — что делать по шагам. Выберите свой уровень.

---

## Вариант 1. «Хочу просто взять картинку и сгладить» (2 минуты, без программирования)

1. **Создайте папку `my_images`** рядом с проектом (если её нет) и положите туда
   любые свои картинки: фото с телефона, скачанные картинки — форматы `jpg`, `png`, `bmp`.
   Можно несколько сразу.
2. **Запустите готовый скрипт:**
   - **Windows:** двойной клик на `запустить_сглаживание.bat`
   - **Linux / macOS:** в терминале `bash запустить_сглаживание.sh`
3. Скрипт сам соберёт программу и обработает **все** картинки из `my_images`
   **всеми методами**. Результаты появятся в папке `my_results`:

| Файл | Что это |
|---|---|
| `<имя>_0_noisy.png` | ваша картинка с добавленным шумом |
| `<имя>_1_gauss.png` | результат гауссова фильтра (для сравнения) |
| `<имя>_1_median5.png` | результат медианного фильтра |
| `<имя>_1_bilateral.png` | результат билатерального фильтра |
| **`<имя>_1_acsf.png`** | **результат нашего метода АКСФ** |

В окне консоли печатается таблица PSNR по каждому методу — видно, что АКСФ выигрывает.

**Как поменять уровень шума:** откройте скрипт Блокнотом и замените `--sigma 25`
на `--sigma 10` (слабый шум) или `--sigma 40` (сильный).

> Если Rust ещё не установлен: скачайте на Windows `rustup-init.exe` с https://rustup.rs
> и запустите (один раз, ~5 минут). На Linux/macOS — команда `curl --proto '=https' --tlsv1.2 -sSf https://rustup.rs | sh`.

## Вариант 2. «Хочу сам поискать картинки» — где их взять

- **Свои фото** — лучший вариант для защиты: «я снял это на телефон и обработал своим методом».
  Фото с телефона отлично подходят: в них много шума в тенях и мелкой текстуры.
- **Скачать готовые:** любая картинка из интернета (например, сайты unsplash.com, pixabay.com,
  commons.wikimedia.org — там свободные лицензии). Классические тестовые картинки из мира
  обработки изображений уже лежат в `my_images/` (бабочка, лена, звёздная ночь).
- **Сгенерировать** — можно прямо в этом чате: попросите «сгенерируй картинку с мелкой
  текстурой», скачайте её и положите в `my_images`.

## Вариант 3. «Хочу запускать отдельные картинки и крутить параметры»

Полная справка по программе:

```bash
./target/release/smoothing_project          # список всех команд
```

Самые полезные команды:

```bash
# одна картинка, цветной режим, шум 25, наш метод
./target/release/smoothing_project denoise -i my_images/foto.jpg -o out.png -m acsf --sigma 25 --rgb

# то же без добавления шума (обработать реальное фото «как есть»)
./target/release/smoothing_project denoise -i my_images/foto.jpg -o out.png -m acsf --rgb

# другие методы для сравнения: -m gauss | -m median | -m bilateral

# поменять параметры нашего метода (по умолчанию: ss=2.0 kmin=0.7 kmax=3.2 c=1.2)
./target/release/smoothing_project denoise -i my_images/foto.jpg -o out.png -m acsf --rgb --sigma 25 --kmax 4.5
```

Без флага `--rgb` картинка обрабатывается в полутоновом (чёрно-белом) виде — так
делаются все эксперименты в отчёте; с флагом `--rgb` — в цвете, обрабатывая каналы
R, G и B по отдельности.

## Вариант 4. «Хочу понять и объяснить код» (это важно на защите)

Преподаватель может спросить любую деталь — и её нужно уметь объяснить. Разбор по отчёту:

- **`src/filters.rs`, функция `acsf`** — ядро метода (три шага: оценка шума → карта
  активности → фильтрация). Этот код подробно разобран в отчёте, разделы 3.2–3.4
  и приложение Б.
- **`src/metrics.rs`** — что такое PSNR, SSIM, EPI и как они считаются.
- **`src/experiment.rs`** — как ставится эксперимент и почему сравнение честное.
- **`src/noise.rs`** — как генерируется шум и почему эксперимент воспроизводим.

**Хороший приём перед защитой:** запустите `demo` на своих фото и покажите результат
на своём примере — это всегда производит впечатление.

Если какая-то строка кода непонятна — пришлите её в чат, я объясню построчно.
Это нормальная практика: понять каждую формулу важнее, чем просто иметь файлы.

## Вариант 5. «Хочу сделать красивое сравнение "до/после" для слайдов»

После обработки запустите:

```bash
python3 сделать_сравнение.py
```

Скрипт соберёт из папки `my_results` аккуратные картинки-сравнения с подписями
(оригинал / шум / гауссов / АКСФ) и положит их в `my_results/сравнения/`.
Такие картинки отлично встают на слайды презентации.

Нет Python — не проблема: пришлите картинки в чат, я соберу сравнение за вас.

## Если что-то не работает (типичные случаи)

**«Не найден Rust (команда cargo)»** — Rust не установлен. Windows: скачайте
`rustup-init.exe` с https://rustup.rs, запустите, нажмите Enter, дождитесь окончания,
перезапустите скрипт. Linux/macOS: `curl --proto '=https' --tlsv1.2 -sSf https://rustup.rs | sh`.

**Windows-скрипт показывает «кракозябры» или закрывается сразу** — откройте PowerShell
в папке проекта и выполните команды вручную (то же самое, что делает скрипт):

```powershell
cargo build --release
.\target\release\smoothing_project.exe demo -d my_images -o my_results --rgb --sigma 25
```

**«не найден каталог my_images»** — создайте папку `my_images` рядом с проектом
и положите туда картинки (или просто запустите скрипт ещё раз — он создаст папку сам).

**Картинка обрабатывается долго** — большие фото (больше 2000 px по стороне) программа
обрабатывает пропорционально дольше. Это нормально; для слайдов достаточно фото до 1500 px.

**Хочу другой уровень шума / другие параметры** — откройте `запустить_сглаживание.bat`
(или `.sh`) Блокнотом и поменяйте `--sigma 25` на нужное значение. Параметры метода
добавляются в конец команды, например: `--kmax 4.5` или `--ss 1.5`.

**Хочу понять каждую строчку кода** — пришлите непонятный фрагмент в чат, разберу построчно.
Это нормальная часть подготовки: на защите важно уметь объяснить код, а не просто иметь его.
