# Сглаживание изображений: адаптивный контрастно-структурный фильтр (АКСФ)

Учебный проект по обработке изображений. Разработан **собственный метод сглаживания** —
адаптивный контрастно-структурный фильтр (АКСФ), реализован на **Rust** и исследован
в сравнении с классическими методами (среднее, гауссов, медианный, билатеральный фильтры).

## Идея метода

Билатеральный фильтр взвешивает соседние пиксели по геометрической близости и близости
яркости (σ_r). Проблема: σ_r — один и тот же для всего изображения, поэтому приходится
выбирать между подавлением шума и сохранением контуров.

АКСФ решает это в три шага:

1. **Оценка шума** σ̂ по самому изображению (метод Иммеркера) — эталон не нужен;
2. **Карта структурной активности** `A(p) = sqrt(max(0, V(p) − σ̂²))`, где `V(p)` —
   выборочная дисперсия яркости в окне. Дисперсия шума вычитается, поэтому шум не
   «маскируется» под структуру;
3. **Адаптивный параметр** для каждого пикселя:

   `σ_r(p) = σ̂ · ( k_min + (k_max − k_min) · exp( −(A(p) / (c·σ̂))² ) )`

   В гладких областях (A ≈ 0) сглаживание сильное (`k_max·σ̂`), на контурах (A ≫ σ̂) — осторожное
   (`k_min·σ̂`). Коэффициенты безразмерные (в единицах σ̂), поэтому один набор параметров работает
   при любом уровне шума и на любом изображении.

Параметры (по умолчанию): `σ_s = 2.0, k_min = 0.7, k_max = 3.2, c = 1.2, r = 5, r_struct = 2`.


## Как попробовать самому (свои картинки)

Подробная инструкция — в файле `КАК_СДЕЛАТЬ_САМОМУ.md`. Кратко:

```bash
# 1. положите свои фото (jpg/png) в папку my_images
# 2. запустите один из скриптов:
#    Windows:      двойной клик на запустить_сглаживание.bat
#    Linux/macOS:  bash запустить_сглаживание.sh
# 3. результаты появятся в my_results — файл <имя>_1_acsf.png это наш метод
```

Ручной запуск и цветной режим:

```bash
# все картинки из папки, все методы, цветной режим, шум 25
./target/release/smoothing_project demo -d my_images -o my_results --rgb --sigma 25

# одна картинка нашим методом (--rgb для цвета, без --sigma шум не добавляется)
./target/release/smoothing_project denoise -i my_images/foto.jpg -o out.png -m acsf --rgb --sigma 25
```

Собрать красивые панели «до/после» для слайдов: `python3 сделать_сравнение.py`

## Результаты (среднее по 3 изображениям и σ = 10, 20, 25, 30, 40)

| Метод | PSNR, дБ | SSIM | EPI | Время, мс |
|---|---|---|---|---|
| Гауссов | 23.07 | 0.5242 | 0.3510 | 16 |
| Медианный 5×5 | 22.06 | 0.4141 | 0.0095 | 83 |
| Билатеральный (универсальный) | 24.15 | 0.5826 | 0.4964 | 156 |
| Билатеральный («оракул», подбор параметров под задачу) | 26.40 | 0.7299 | 0.5495 | — |
| АКСФ без адаптации (контроль) | 25.62 | 0.6771 | 0.5281 | 175 |
| **АКСФ (наш метод)** | **26.14** | **0.7216** | **0.5484** | 179 |

Вывод: метод превосходит все классические фильтры с фиксированными параметрами
(до **+3.07 дБ** PSNR) и почти достигает «оракула» (−0.26 дБ) без какого-либо
подбора параметров под задачу.

## Сборка и запуск

```bash
cargo build --release
./target/release/smoothing_project            # справка по подкомандам

# сгладить изображение нашим методом (шум sigma = 25 добавляется автоматически)
./target/release/smoothing_project denoise -i data/clean/baboon.png -o out.png -m acsf --sigma 25

# полный эксперимент (все методы × уровни шума) -> results/tables/results.csv
./target/release/smoothing_project bench -d data/clean -o results --noise 10,20,25,30,40 --save-sigma 25

# калибровка параметров, сравнение конфигураций, чувствительность к оценке шума
./target/release/smoothing_project sweep -d data/clean --param k_max --values 2.0,2.4,2.8,3.2 --noise 20,30
./target/release/smoothing_project tune  -d data/clean --configs "2.0,0.7,3.2,1.2,5,2" --noise 20,30
./target/release/smoothing_project sens  -d data/clean --noise 10,20,30,40
```

Методы для `denoise -m`: `box`, `gauss`, `median`, `bilateral`, `acsf`.

## Воспроизводимость

Генератор шума детерминирован (фиксированный seed = 12345): повторный запуск `bench`
даёт в точности те же числа. Пересборка документов: `python3 docs/build_report.py`
и `python3 docs/build_slides.py` (требуется `python-docx`, `python-pptx`).
